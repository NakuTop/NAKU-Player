# macOS 3.2.3 响应与播放修复

## 观察与修复

- 本机 3.2.2 HomePod 日志出现 `POST /feedback CSeq 12: Control response timed out`。同一会话的正常控制回复约 1–3 秒；最后一次请求等待期间 NTP 仍正常，旧实现恰在 4 秒终止发送。控制请求改为独立的 25 秒总期限，跨越短轮询仍等待原响应，不重发密文、不重置序号。关闭会话主动唤醒阻塞读取；空闲控制通道才尽力发送 TEARDOWN。事件监听提前到音频 SETUP 前启动，避免连接阶段没有人应答事件。
- 音频 RTP、120/200/300 ms 接收目标与既有 15/40 ms 漂移缓冲参数不变。校时线程用 socket readiness 唤醒，空闲时不再每 2 ms 查询一次。真实声学延迟、长时间播放连续性需在 HomePod 上验收。
- 本机主页可见整块无图区域。高清横图查找失败会丢弃原目录海报；改为先按原比例显示已有海报，找到合格横图再升级，高清图片下载/解码失败也可回退到已有海报。保留内存解码上限、只预取当前与邻页以及现有布局。
- 聚合后的条目可能使用豆瓣图片，但 sourceId 已不是豆瓣；图片请求头按实际 CDN 主机补齐，不再依赖条目来源。图片传输复用客户端和已成功的网络路径；代理设置变化时等待在途请求结束再释放旧客户端；卡住的图片正文有空闲超时，释放请求而不是永久占用下载队列。
- 历史点击原先在主页等待详情 API，之后才 push 播放页。已有有效线路/集数快照时立即进入播放页、保留进度。旧媒体地址失效后只刷新同一作品一次，按 URL 或唯一线路/集名重新匹配，继续保留原有自动选源与有限换源逻辑。历史损坏、无法明确对应集数的情况仍走详情核对。

## 验收范围

新增真实本地 socket-pair 测试：4.2 秒延迟的加密回复、分段 HAP 数据、下一条 CSeq/nonce 连续性、无回复超时失效、等待中关闭。原生声卡、会话取消与音频时钟夹具一起验证。

Flutter 覆盖历史入口无需详情响应、过期链接与集数重排、图片连接复用与退役、正文超时取消、横图失败后的实际像素回退，以及原有播放偏好、布局、线路选择与图片边缘组合。自动化结果、正式构建和本机 UI 观察分别记录；未做过的 HomePod 长时间硬件验收不计为通过。

2026-11-11 本地结果：204 项 Flutter 回归通过；修改文件静态分析无问题；HomePod 协议、会话与驱动三个原生检查通过；macOS Release 构建完成。详情页两项旧栅格测试在未改代码的基线上也失败，原因是第一次取图在异步海报取色前完成。测试现等待同一海报状态再比较外部窗口底色，并检查实际次要文字的对比度至少 4.5:1；没有为通过测试调暗产品光效。

本机安装后确认版本为 3.2.3+119，主页横图正常显示，历史条目直接进入对应集数并从已有进度播放。虚拟声卡沿用既有程序身份校验；本次新版的本机声卡授权由系统安装器处理，没有放宽校验规则。协议夹具已覆盖旧四秒边界，但不能代替用户对实际扬声器连续出声的确认。

## 详情页提前检测画质（3.2.3+120）

详情页原先等待全部片源目录加载完成才检测媒体；任何慢源都会拖住已经可用的源。现在目录与媒体独立调度，各自最多三个并发，先检测每个源的优选版本，再补其他版本，逐项更新原有片源按钮。总检测期限 12 秒，单项媒体读取 4.5 秒；离开详情页取消读取。推荐仍优先遵循用户的源顺序，再比较源内版本画质。

单项快速采样从 1.5 MiB 降至 256 KiB；MP4 尾部索引只在需要时补一次范围请求，前后合计最多 512 KiB。相同 URL、请求头和网络状态的结果可跨详情页复用一分钟，最多保留 128 项，手动重测会清理。不启动播放器或音频解码器，视频头解析与 AES 解密在后台 isolate 中执行。

支持普通 HLS、AES-128 HLS、H.264/HEVC TS 视频头、MP4 初始化信息和尾部索引。按被抽样分段对应的 KEY、IV、媒体序号和 BYTERANGE 读取；不把后续分段的密钥误用于第一段。SAMPLE-AES 或非 identity KEYFORMAT 保持未知，不尝试 DRM 密钥。主清单优先最高像素分辨率，视频头已确认的尺寸在后续速度采样失败时仍保留。请求密钥只在本次内存中使用。

界面在详情页片源按钮中展示检测到的分辨率与速度；网页解析线路或不可达片源明确显示未读出，不再用“播放后可检测”作为详情页检测结束的状态。没有减少原有布局与操作。

协议依据：[RFC 8216](https://www.rfc-editor.org/rfc/rfc8216.html) 的 AES-128、IV、初始化段和字节范围定义；HEVC SPS 字段对照 [FFmpeg HEVC 参数集解析](https://github.com/FFmpeg/FFmpeg/blob/master/libavcodec/hevc/ps.c)。

2026-11-12 验证：194 项相关 Flutter 回归通过，1 项需要外部本地 MP4 的测试跳过；随后新增初始化段成功、媒体段失败仍保留分辨率的回归，并对受影响三组测试复测，21 项通过。其中包含页面未打开播放器就显示两源分辨率、慢目录不阻塞其他源、跨详情缓存、显式/隐式 IV、密钥轮换、HEVC 裁切和采样上限。修改文件静态分析通过，Release 构建完成。真实豪华影视抽查在当前网络 5 秒超时，未获得分辨率，不能记作真实片源验收通过；提供显式启用的 live 测试便于网络恢复后复核。
