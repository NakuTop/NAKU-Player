# Android 3.2.0 (116)

手机端保留原有原生能力，补齐 PWA 操作：统一深色首页与五项底部导航、Home Display / 下载 / 更新入口、搜索返回主页、触控播放手势、横屏操作与分辨率。两款 Android 包均移除独立动漫分类入口，既有下载数据不做迁移删除。

新下载的 Cinema 影视在下载目录内保存 `cinema-danmaku-v1` 快照。后台串行获取所有公开弹幕来源与完整时间线，分块存盘；播放仅读取当前时间窗。来源失败不阻塞视频下载，快照独立于在线缓存，删除前取消任务，崩溃残留在下一次快照时清理。已有下载不伪造历史快照。

投屏保持同账号 NAS 授权、私有局域网地址校验、加密和重放保护。手机前台提前发现电视并缓存最多五分钟的内存授权，失效/退出/切换账号会清除。TV 已认证请求直接唤醒并进入播放器。此变更不包含任何 NAS 密码或个人地址。

验证覆盖手机 320/390 像素竖屏与 844 像素横屏、搜索返回、移除动漫入口、手势和按钮互不冲突、倍速恢复、离线弹幕全时间线/多选/取消、下载恢复、NAS 会话、聚合搜索与电视导航。真实设备的投屏延迟、播放、系统 WebView 与厂商兼容性由设备测试确认。

APK 应用 ID 和签名保持不变，版本号 3.2.0、versionCode 116。手机与 TV 分别使用各自更新源；不修改 macOS 的 Sparkle appcast。
