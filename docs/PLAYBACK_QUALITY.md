# 高清播放

在主侧栏选择「高清直链」，粘贴自己的 HTTP/HTTPS 视频地址，可直接播放或收藏并播放。支持播放器能解码的 HLS、MP4、MKV 等媒体；网页链接使用「网页影院」。有效期链接过期后须重新添加。直链收藏保存在本机片库，不会用它的名称请求公网电影目录或评分服务。

## 画质与流畅度

「设置 → 画质与流畅度」与播放中的画质面板使用同一份偏好。电影、剧集和动漫均在「更多选项 → 画质信息与处理」打开；全屏也可使用。

- **优先最高码率**：打开多清晰度 HLS 时选择已提供的最高码率。关闭时优先约 5 Mbps，适合网络带宽有限的情况。换片生效；没有 4K 轨道的视频不会变为 4K。
- **影视缓冲上限**：32、64、128、256 MB，默认 128 MB。下次打开影视播放器生效；低内存策略启用时仍优先限制到 2 MB。动漫沿用原播放器的独立缓存预算。
- **影视精细缩放**：使用 GPU 高质量缩放、色度重建与去色带。动漫仍可启用 Anime4K；两者都是本地处理，无法恢复原视频中不存在的细节。
- **帧节奏平滑（实验）**：尝试 mpv 的显示同步与时域混合，是否生效以实际面板中的「显示同步」为准。当前输出不支持时会明确提示。此功能不是 AI 运动补偿插帧；本版未集成 RIFE / SVP，所带 FFmpeg 未包含 minterpolate 滤镜。

画质面板读取解码器实际分辨率与原视频帧率，不采信标题里的“4K/60帧”。「视频轨道 / 清晰度」仅显示媒体实际暴露的轨道，不保证每个接口都有多个选择。网络供给速度持续低于码率时，增大缓存不能无限避免停顿；可关闭最高码率优先或换线路。

最高码率和帧节奏处理的技术依据：[mpv 官方手册](https://mpv.io/manual/stable/)。可以使用 [Apple 官方 HLS 测试样片](https://developer.apple.com/streaming/examples/)检查解码能力；样片用于技术测试，不能替代可用的影视片库。

## 手势与片库

桌面视频区域单击切换播放/暂停，双击进入或退出全屏；双击不会额外触发单击。控制栏按钮单独响应。全屏切换保留当时的播放状态，暂停的视频不会因此自动播放。

主侧栏「我的收藏」「继续观看」包含电影、剧集和动漫。动漫收藏只有收藏/取消收藏两种界面状态，原来保存的追番状态仍留在原存储内以兼容同步。右键可删除；历史支持滑动删除。删除动漫作品时同时删除它在本机的各源记录，可在 5 秒提示中撤销；若期间产生了新收藏或新进度，撤销不会覆盖新记录。取消本地收藏不删除 Bangumi 账号中的远端记录。

## 加载与连接排查（1.10.0）

视频可以解码，但系统代理或 CDN 的 TLS 连接失败时，增加缓冲或开启超分无法解决。默认仍遵循网络代理设置；发生连接失败时可点击「启用视频直连并重试」，或进入「设置 → 网络设置 → 视频直连」。这个选择只改变媒体播放和下载，目录、评分、动漫检索继续沿用原配置。关闭后重新播放即可恢复跟随代理。

解析初始化、导航、获取媒体地址共用 25 秒（影视）/调用方指定的期限；提前订阅解析结果，保留无扩展名 HLS 的格式提示和网页来源请求头。已出现明确网络错误且视频持续 6 秒无进展时尝试同集其他线路，暂时性错误恢复后不会强制中断；无明确错误仍保留启动超时与播放进度看门狗。准备完成需要画面尺寸，单独取得时长不再视为成功播放。

当前 macOS 包携带 mpv 0.36.0。采用该版本支持的 `vd-lavc-software-fallback=3`，保留硬件解码失败后的软件回退；不把 TLS 错误误判为解码失败。电影播放器禁用未配置路径的磁盘缓存，继续使用受设置限制的 RAM 缓冲。技术依据：[对应版本的官方选项说明](https://github.com/mpv-player/mpv/blob/v0.36.0/DOCS/man/options.rst)。

这些改动改善加载链路，不会修复服务端已下架、禁止访问或本身损坏的片源，也不改变视频的原始分辨率或帧率。
