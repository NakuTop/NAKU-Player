# macOS 历史记录与视频缓存

验收构建：3.0.15（95），基于 3.0.14（94）。

- 默认视频分片预算为 2048 MiB（2 GiB，2,147,483,648 字节），按文件内容长度计量。Finder 十进制容量、分配块及归属索引会产生显示差异。
- 超额时优先淘汰最近访问时间最早的分片；正在向播放器提供数据的分片暂缓删除，并在请求结束后重新检查额度。
- 新下载及重新命中的分片记录所属历史条目的身份，索引只保存分片哈希和条目 key，不保存请求 URL 或认证头。
- 历史中移除条目后，即使未超额也清理其分片。共用分片只要还有一个历史归属就保留；正在播放的条目延迟到会话关闭再清理。
- 包含合并的来源身份，避免历史换源后误判为无归属。历史读取失败时不采用空历史作为删除依据。
- 启动读取归属索引；历史变化通知触发清理。额度清理、归属索引写入和分片落盘串行，减少竞争。普通进度刷新若历史身份未变化则不重新扫描。
- 旧版本分片没有归属索引，不能推断其对应剧集。因此旧分片继续受 LRU 额度管理，播放再次命中时补上归属。不会将未知归属直接当作历史外内容删除。
- 历史以整部作品/季度条目保存；更换当前集不会删除该条目下其他集的缓存。
- 不更改当前已安装应用，不直接修改用户缓存目录，不发布在线更新。

验证包括真实 HTTP 分片下载及索引落盘、重启恢复、历史删除、共用分片、播放会话保护、旧缓存保留、LRU 额度及历史读取失败。安装后仍需实际播放及历史删除验收。
