# NAKU 2.0 使用说明

## 片源健康与测速

在「设置 → 影视片源」点击探活。最多同时检测 3 个接口，可取消尚未开始的检测。目录接口和实际视频健康分别记录，健康记录按钮显示最近 12 次检查；记录只保存状态、时间和指标，不保存带签名的视频地址。反复失败的接口临时冷却 2 / 10 / 60 分钟，过期可重试，也可手动解除。冷却不删除来源、不改用户开关或排序。健康数据超过 7 天后不用于启动判断。

2.0.1 起，从详情页开始播放电影或剧集，首个视频画面就绪后自动在后台比较线路。当前视频继续播放，测速完成后仅自动选择一次，并保留当时的进度、播放 / 暂停及一起看缓冲等待后的播放意图。播放器下方和选集面板以橙色卡片、大号 Mbps 数字及徽章显示「本次最佳」，同时展示本轮完成数量。

推荐只比较可确认是同一作品、同一集的已读取线路，排除视频读取失败及无效速度；优先选择满足 HLS 清单码率 1.3 倍余量的线路，再比较实测速率、首字节响应，完全相同时保留顺序。没有码率信息的线路按实测速度比较。清单分辨率不等于已解码画质，实际尺寸和帧率仍可在「画质信息与处理」查看；推荐只表示本次已测线路中的结果，不保证全片持续带宽。

最多读取 12 个不同媒体地址、同时 2 条、每条最多采样 2MiB / 6 秒，自动一轮最多 10 秒。初次可短暂等待已在读取的线路加入，但不阻止当前视频播放。相同地址、请求头和格式的重复线路复用样本；测速期间暂停额外预缓存、下一集预热和重复测速，让当前播放继续使用网络。网页解析器不在后台导航其他页面，当前已解析线路会使用实际媒体地址及请求头；未解析的线路需先播放，离线播放不测速。

主动换线、选集、关闭播放器或关闭「打开影片时自动选线」会取消未完成的自动切换。该开关记住用户选择；重新打开影片可再次比较。选集面板点「重新测速」只更新推荐，点「使用推荐线路」才切换，避免手动测速抢回已选线路。旧集数结果不会标成新集数最佳；测速后真正播放失败的线路会移除推荐并沿用换线回退。访问令牌过期、地域限制、网络波动或解码错误仍可能需要重试或手动选线。

## 后台预缓存与下一集

「设置 → 播放缓存与片库迁移 → 视频缓存」默认开启 HLS 分段磁盘缓存，空间上限 2048MB，向前预读 300 秒，下一集预热 90 秒，可调整或关闭。缓存按地址、请求头和分段范围区分，避免混用不同鉴权数据；达到上限淘汰较久未使用的数据。一个后台媒体请求逐段填充，当前播放有网络请求时让出带宽，缓冲时取消预取。暂停后仍可填充。

预热使用当前路线已确认的下一集直接 HLS 地址，不为后台缓存导航网页解析器。当前清单保留独立音轨、字幕、初始化片段、字节范围和 AES 密钥转发；密钥不保存到缓存。直播清单不持久保存或预取。直接视频文件继续使用底层播放器缓冲，不复制整部文件到此分段缓存。清理临时缓存不删除下载文件。片源地址改变或过期时无法保证命中，缓存不能代替离线下载。4K 与高帧率取决于真实视频，本版本不会把 1080p 标成真 4K，也没有 AI 插帧。

## 订阅与批量导入

「设置 → 播放缓存与片库迁移 → 订阅与导入」提供订阅地址、粘贴 JSON、文件导入和导出。支持 `sources` / `vod` 列表或映射，以及 TVBox `sites` 中类型 0 / 1 的直接 MacCMS API；文件最多 2MiB、500 个来源。不执行 JS、JAR 或 Spider 配置。导入先预览数量，按接口地址去重；已存在片源的名称、开关和优先级保留，新来源追加到末尾。

订阅在启动时最多每天刷新一次，也可手动刷新。取消订阅保留已导入来源，远程删除来源不会自动删除本机来源。订阅是用户提供的配置地址，软件不保证其内容授权或线路画质。

## 完整片库备份与迁移

「设置 → 播放缓存与片库迁移 → 备份与迁移」导出版本化 JSON，包括影视和动漫收藏历史、下载任务记录、片源顺序及订阅、动漫规则、弹幕屏蔽和 Bilibili 匹配、评分关联、磨砂外观、网站收藏、豆瓣主题和主要设置。默认排除账号令牌、WebDAV 密码及一起看房间配对；可勾选包含账号设置。自定义片源请求头仍属于来源配置，请把备份保存在自己的安全位置。macOS 钥匙串内的弹弹play密钥不导出。

在另一台 2.0 设备导入，会先验证整份备份和 SHA-256，保存当前资料的恢复副本，再合并。保留本机来源的设置和顺序，冲突编号重新映射，作品收藏去重，历史取较新的完整进度；动漫分集进度也按更新时间保留。已有本机评分、外观、主题和其他附加文件优先，空白设备才恢复对应文件。导入后重启软件以载入这些附加设置。

视频下载文件、截图和图片 / IMDb 大型缓存不在 JSON 中。离线片库迁移需另外复制下载目录并在下载设置选择对应目录；导入时会把下载记录关联到当前下载目录，复制的视频可继续离线播放；缺失或未完成的集数保持暂停，不自动启动网络下载。机器上的绝对路径和目录访问授权不跨设备恢复。导入失败时程序尝试恢复原资料，恢复副本仍保留在本机 `cinema/backups` 目录供恢复使用。

## 字幕、音轨与播放器

影视播放器更多菜单提供截图、字幕与音轨；宽窗口也有独立字幕按钮，全屏菜单保持可用。可切换线路内音轨与字幕，加载 SRT / ASS / SSA / VTT 本地字幕或 HTTP(S) 字幕链接、加载本地外部音轨；有多条字幕轨时可启用第二字幕。底层原生播放器支持字幕延迟 ±10 秒，默认音轨 / 字幕语言会保存，新打开作品生效。没有提供相应轨道的线路不能自动生成字幕或配音。

选集面板可倒序、定位当前集，保留上一集 / 下一集、季下载选择、收藏、倍速、画中画、超分和一起看。截图保存使用原视频画面，系统文件对话框选择位置。打开面板与切换全屏保持播放状态。

## 一起看与邀请

见[双人一起看](WATCH_TOGETHER.md)。双方使用 2.0，可共同等待缓冲、设置每端独立时间偏移、共享作品链接 / 二维码。电影、剧集与动漫共用配对；动漫由 Bangumi 编号解析到对方自己的动漫规则，不通过影视接口查动漫。

邀请仅含作品和集数、可选进度与房间信息。接收者确认后才打开，播放使用自己的来源。它不会传输媒体、屏幕、视频地址、请求头或账号凭据。二维码需在安装 NAKU 2.0 的设备打开；目前发布的是 macOS 客户端。
