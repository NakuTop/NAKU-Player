# 3.2.0 统一片源顺序与详情对比

macOS、Windows、Android 手机和 TV 共享同一播放策略；PWA 0.3.8 使用相同排序。源顺序优先，同源画质优先，同画质再比较速度。真实视频分辨率覆盖片源标签，TD/TC 不因像素较高而排在高清版本之前。所有提供方适用同一逻辑，删除巨量双端独立预检。

详情页为增量修改。保留 macOS 原有布局与完整操作，在左下片源区补充检测和自动推荐。海报、评分与氛围光不随测速结果重载。原生检测并发 2、45 秒总预算；关闭详情取消检测。电影多版本按同片匹配，连续剧按同集匹配，失败换源保留进度。

本次新增排序/取消/迟到结果/懒加载优先源测试，覆盖实际画质、速度次序、电影 TD/HD/4K、三种桌面/移动平台启动以及 TV 自动选线。

背景霜玻璃像素阈值测试的 2 项失败也在变更前 HEAD 7da3c4cc 复现（14 对阈值 10），本次不修改该背景实现或放宽测试；其余详情布局、就绪、交互检查继续通过。
