# 和同伴一起看

NAKU播放器通过 Syncplay 服务器同步播放、暂停和进度。视频由每个人自己的播放器和片源加载；它不传输影片、屏幕或声音通话。跨国观看时，双方都需要能访问所选视频以及同一个 Syncplay 服务器。

## 开始一次观看

1. 双方安装同一版本的 NAKU播放器，分别找到同一作品、同一季和同一集。优先选相同剪辑版本，各自确认能正常播放，再暂停在开头。
2. 第一位观众点击播放器里的 **一起看**，使用默认服务器 `syncplay.pl:8996`，保留随机生成的房间名，填写自己的昵称，点击 **创建 / 加入房间**。
3. 点击 **复制房间信息**，通过自己的聊天软件发给同伴。软件不会替你发送邀请。
4. 同伴打开 **一起看**，填入完全相同的服务器和房间名，使用另一个昵称，点击 **创建 / 加入房间**。房间名区分大小写，注意不要多空格。
5. 确认连接状态及作品 / 集数匹配。双方准备好后由一人开始播放。播放、暂停和跳转会同步；操作时给另一端一点响应时间，避免同时反复拖动进度。

随机房间名用于降低偶然重名，并不是访问密码或身份认证。只把房间信息分享给你的同伴；知道同一公共服务器和房间名的人可能加入。连接使用 TLS，但这不意味着端到端加密：Syncplay 服务器仍负责接收和转发同步消息。软件不向同步服务器发送实际媒体 URL。

播放界面快捷键：空格播放 / 暂停，F 全屏，Esc 退出全屏，左右方向键快退 / 快进 10 秒，E 打开线路与选集，P 画中画，W 一起看，B 收藏。

## 画质、缓冲与换线

双方可以选择各自网络更流畅的线路，但必须是同一作品与集数。网络和来源决定实际画质；标题里的“高清”或“4K”不保证视频分辨率。播放器显示的媒体分辨率更有参考价值。

先让两端各播放片刻，确认缓冲稳定，再加入房间。某一端加载缓慢时，可共同暂停等待、降低该端的播放负担，或换到稳定线路。超分辨率是本地 Anime4K 处理，会增加图形处理负担；卡顿时先关闭它。同步服务不会提升片源带宽，也不保证公共服务器始终可用。

线路失效时，播放器会在能确认相同作品、相同集数的其他线路中尝试接续。双方不必使用同一个站点，但换源之后应核对画面。若新线路有片头、广告、删减或不同剪辑，同一个时间点可能对应不同画面；先共同暂停并用进度条校准，必要时选择同一版本。当前没有长期保存的个人时间偏移设置，重复出现固定偏差时应优先统一剪辑版本。

## 连接或同步不正常

| 现象 | 处理方式 |
| --- | --- |
| 连接中或连接失败 | 确认双方填写同一 `主机:端口`，网络可到达该服务器；稍后重试，或共同改用可访问且支持 TLS 的 Syncplay 服务器。 |
| 已连接，但没有同步 | 核对服务器、房间名、作品、年份 / 季和集数。作品身份无法确认时，播放器会阻止误同步。 |
| 有人断网或服务器断开 | 先暂停；查看一起看状态，网络恢复后重新连接同一房间，双方再次确认作品和进度。 |
| 进度反复跳动 | 先由一人操作，另一人暂停拖动；检查是否选择了不同剪辑，或有不认识的房间成员。 |
| 只有一方缓冲 | 该端先独立检查视频线路和网络，再共同恢复播放。同步服务器和视频来源是两条独立连接。 |

结束时点击 **一起看 → 断开**，或退出播放页。语音聊天可使用双方已有的通话软件；NAKU播放器的一起看不包含语音或视频聊天。
