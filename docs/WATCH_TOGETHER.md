# 和同伴一起看

NAKU播放器通过 Syncplay 服务器同步播放、暂停和进度。视频由每个人自己的播放器和片源加载；它不传输影片、屏幕或声音通话。跨国观看时，双方都需要能访问所选视频以及同一个 Syncplay 服务器。

## 配对与跟随观看

1. 双方安装 NAKU播放器 2.0.0 或更新版本。在首页侧栏或播放器中打开 **一起看**。
2. 第一位观众使用默认服务器 `syncplay.pl:8996`，保留随机生成的房间名，填写自己的昵称，创建或加入房间。
3. 点击 **邀请链接与二维码**，复制链接通过自己的聊天软件发给同伴。对方打开 `naku://watch` 链接并确认后可加入房间并打开同一作品；也可在「设置 → 播放与片库 → 订阅与导入 → 打开作品邀请」粘贴链接。双方使用不同昵称。软件不会替你发送邀请。
4. 配对会持续保存。退出影片、切换作品以及重启软件都不解除配对；网络中断后会自动尝试重连。双方软件均在线时，一起看面板显示对方当前作品和集数。
5. 一人开始观看后，另一人在一起看面板点击对方旁边的 **跟随观看**。播放器从自己启用的片源中查找同一作品、年份 / 季和集数，打开匹配内容并取得对方进度。完成后，对方收到加入观看的提示。
6. 双方观看同一集时，播放、暂停和跳转会同步。操作时给另一端一点响应时间，避免同时反复拖动进度。对方换了作品或集数后，可再次主动跟随；收到作品变化不会强制打断自己的播放。

若当前来源中没有能确认的相同作品或集数，软件会提示匹配失败。可先启用其他来源再重试。配对本身不保证不同片源有相同内容；双方优先选择相同剪辑版本。

随机房间名用于降低偶然重名，并不是访问密码或身份认证。只把房间信息分享给你的同伴；知道同一公共服务器和房间名的人可能加入。连接使用 TLS，但这不意味着端到端加密：Syncplay 服务器会转发作品名称、年份 / 季、集数和同步消息。软件不向同步服务器发送实际媒体 URL、片源请求头或账号凭据。

播放界面快捷键：空格播放 / 暂停，F 全屏，Esc 退出全屏，左右方向键快退 / 快进 10 秒，E 打开线路与选集，I 画中画，W 一起看，B 收藏。

## 画质、缓冲与换线

双方可以选择各自网络更流畅的线路，但必须是同一作品与集数。网络和来源决定实际画质；标题里的“高清”或“4K”不保证视频分辨率。播放器显示的媒体分辨率更有参考价值。

双方使用 2.0 时，默认启用缓冲协调：一端加载或缓冲时暂停双方，恢复后继续原本在播放的内容；手动暂停会保持暂停。可在面板关闭等待，或选择「先独立播放」。对方断线、离开作品或缓冲状态过期后不会永久阻塞。旧版本不参与 2.0 的缓冲协调。超分辨率是本地 Anime4K 处理，会增加图形处理负担；卡顿时先关闭它。同步服务不会提升片源带宽，也不保证公共服务器始终可用。

线路失效时，播放器会在能确认相同作品、相同集数的其他线路中尝试接续。双方不必使用同一个站点，但换源之后应核对画面。若新线路有片头、广告、删减或不同剪辑，同一个时间点可能对应不同画面；请双方选择相同剪辑版本。一起看面板提供每端独立的「版本时间偏移」，范围 ±600 秒。例如你的版本比对方多 20 秒片头，将自己的偏移设为 +20 秒；对方无需修改。不同剪辑的多处删减仍建议换成相同版本。

## 连接或同步不正常

| 现象 | 处理方式 |
| --- | --- |
| 已配对但正在重连 | 确认双方网络可到达同一服务器；可在面板手动重连，或解除后共同改用支持 TLS 的服务器。 |
| 对方在线但未在播放 | 等对方打开影片，或让对方跟随自己当前播放的内容。 |
| 没有找到同一集 | 检查双方片源、作品年份 / 季和集数，启用其他来源后再试。无法确认身份时不会误同步。 |
| 等待对方进度 | 保持对方播放器开启，等待连接恢复；未收到有效进度前不会用自己的旧历史覆盖对方。 |
| 进度反复跳动 | 先由一人操作；检查是否选择了不同剪辑，或有不认识的房间成员。 |
| 正在等待缓冲 | 等待另一端就绪，或在面板选择先独立播放；同步服务器和视频来源是两条独立连接。 |

不再需要配对时，点击 **一起看 → 解除配对**。仅退出播放页会继续保留配对；关闭软件期间无法接收实时提示，重新打开后会尝试恢复连接。一起看不包含语音或视频聊天，可使用双方已有的通话软件。

2.0 起，电影、剧集和动漫共用配对与房间。动漫邀请使用 Bangumi 作品编号和集数，由对方已安装的动漫规则找播放线路；不能确认同一季或集数时会提示，影视接口不会参与动漫解析。详情页的邀请不含进度，播放器或房间面板的邀请包含当前进度。二维码需在安装了 NAKU 2.0 的设备打开；它不是网页播放器链接，暂未发布 iOS / iPadOS 客户端。
