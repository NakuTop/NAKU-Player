# macOS 3.1.10 (115)

## Fix and evidence

PiP reused the main NSWindow at floating level with automatic collection behavior. On this Mac, the green button changed to Zoom and enlarged PiP without entering fullscreen. The native window now explicitly supports primary fullscreen, restores PiP level/aspect/normal geometry before entering, and synchronizes the player PiP controls on native entry.

An in-flight PiP entry could also race the player fullscreen request; a failed geometry operation left floating level behind while the Dart PiP flag remained false. Fullscreen now waits for PiP completion, uses native state, and failed PiP entry restores the window. Both regression cases fail against the prior HEAD and pass against the fix.

Aiyifan explicit JSON/plain-text 403/1009 is classified as regional restriction on both clients, without repeated signature refreshes. Other providers continue independently. This does not remove upstream regional policy.
