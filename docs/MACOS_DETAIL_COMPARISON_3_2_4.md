# macOS 3.2.4（124）详情页片源检测与播放选择

巨量 API 的完整电影条目名为“播放”，其他 API 使用“正片”或“TC / HD”。旧跨源匹配只接受部分完整电影标签，导致目录读取成功后其他源仍没有检测候选。统一使用电影版本分类，并将“播放”纳入完整影片标签；电视剧集号、上下部和预告保持原匹配约束。

删除全局 12 秒截止和 24 个目标上限，慢返回的目录继续加入检测。目录与媒体各最多三个并发，每项媒体最多九秒，批次十秒收尾；同地址合并，离开详情页取消。每个源先获得检测机会，再补同源其他版本。片源按钮优先展示已测媒体结果，避免未测网页线路遮住结果。

保留详情页布局和源排序。按钮显示画质等级与 Mbps，推荐改为小勾，精确尺寸与响应时间放入悬停提示。

## 验证

- 56 项定向测试通过，1 项外部文件夹具按既有配置跳过；静态分析无问题。
- 真实 API《生化危机：爆发夜》在未创建播放器的情况下，五个源均完成采样：巨量、豪华、极速、光速 1920×800，最大 1920×1080；该次全部完成 12.887 秒。速度为当次网络采样，不是恒定性能指标。
- opt-in live 测试：NAKU_LIVE_DETAIL_PROBE=1 flutter test --no-pub test/features/cinema/cinema_detail_comparison_live_test.dart。可用 NAKU_DETAIL_QUERY 指定影片，NAKU_DETAIL_PROBE_REPORT 写入证据。

本机安装验收：应用首页版本 3.2.4+121；直接进入《奥德赛》详情，未播放就看到巨量、极速、光速、最大均为 1080p，分别有速度值。豪华本轮检测未连通。该 UI 结果与五源都成功的《生化危机：爆发夜》API 实测分开记录。49 个 Mach-O 的签名、双架构、最低系统版本及沙箱标识核验通过。旧版保存在本机 installed-backups 目录。此版尚未公开发布。

## 122 本机预览：最快片源光晕

详情页按当前显示版本的实测 Mbps 标记最快可用源，相同速度保留源排序，不改变播放推荐。使用海报色调、不等长的模糊光带与局部柔影；其他片源背景轻微暗化，原有文字、布局与点击行为保持。检测结果切换时 650 ms 淡入淡出，减少动态效果时立即切换，没有循环动画或后台计时器。

27 项比较调度与详情页回归通过，静态分析无问题。

已安装本机 3.2.4+122 并观察实际详情页：《奥德赛》五源均显示速度，巨量 4.7 Mbps 为当次最快，按钮边缘出现非均匀柔光，其他源背景较暗，文字保持可读。未开始播放。签名与 49 个双架构二进制核验通过；本次尚未正式推送。

## 124：开始观看跟随发光片源

详情页自动播放选择改为当前发光的最快可用源；无测速结果时仍使用原有顺序。进入播放时固定该候选，避免播放器二次选择覆盖。用户手动选源或线路时保留选择；锁定线路同时记录所属作品来源，避免自动推荐切源后手选线路又回到旧源。

20 项详情页测试通过，其中包含默认最快源、手选其他源、手选线路三个播放目标断言。静态分析无问题。

正式版以 124 为最终构建，包含 121–124 的片源检测、彩色柔光和最快片源默认播放更新。
