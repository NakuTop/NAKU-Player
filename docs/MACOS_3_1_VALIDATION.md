# macOS 3.1.0 验证与验收

本次基于 3.0.19（99）开发，构建号 100。保留片库、下载、代理、字幕、弹幕、既有 HomePod 发送算法与更新签名身份。

## 自动验证范围

- 弹幕：原协议 fixture、匹配一致性、大批量纯值解析、gzip 大小限制、首赢取消、外部取消、关闭客户端。
- 电源：读取 macOS 系统低电量模式，事件优先于迟到的初始查询，原生桥不可用时保留普通暂停策略。
- 窗口：当前屏幕工作区、断开屏幕、负坐标、小屏尺寸和无效几何值；影院与 WebView 共用恢复函数。
- 暂停：30 秒宽限、后台／系统低电量模式暂停即时节流、正常播放及启动／缓冲豁免、恢复原预算、取消计时与慢写序列化。
- 缓存：真实临时文件统计、主动清理保护正在播放片段、超配额清理尾部保护、非缓存文件保留、日常配额回收。
- HomePod：取消和过期采集启动、启动与恢复串行化、网络路径比较；采样健康状态、静音与历史累计计数不误判、诊断白名单。
- 保留仓库 CI 的影院全量回归与 macOS Release 构建、通用架构和严格代码签名检查。

## 缓存策略依据

mpv 的 `cache-secs` 与 `demuxer-readahead-secs` 共同决定时间预读上限，应同时调整。长暂停将两项降为 1 秒，恢复时还原 86400 秒的容量优先策略，不降低 `demuxer-max-bytes` 或清除已有缓存。已经进行中的网络请求可能完成，节流不等于立即断开全部网络。

依据：[mpv 官方缓存选项](https://mpv.io/manual/stable/#cache) 与 [demuxer-readahead-secs](https://mpv.io/manual/stable/#options-demuxer-readahead-secs)。

## 必须区分的实机验收

自动化不能替代下列体验验证：

1. 海外弹幕较多的剧集：播放开始、拖进度、切集保持流畅，退出后无旧弹幕回写。
2. 外接屏上进入画中画，拔屏后退出；窗口完整落在现有屏幕内。另验证全屏与菜单栏、Dock、不同缩放。
3. 暂停 30 秒后观察流量下降，继续播放／缓冲恢复；系统低电量模式下暂停即减少预读；关闭暂停节流开关后保持原行为。
4. 播放时清理视频分片缓存，当前播放继续，下载管理与观看记录保留。
5. HomePod 连续播放、暂停与静音的健康状态；复制诊断不包含地址或凭据。
6. HomePod 开启时让 Mac 睡眠／唤醒，切换 Wi-Fi 与有线网络，或在“正在连接”时关闭；确认恢复本机声音，状态解释明确，重新开启可用。

未完成的实机验收不能在发布说明中标为通过。正式发布和软件内更新源须另行激活。
