# 3.1.0（101）弹幕修订

## 操作

播放页 → 弹幕 → 选择弹幕来源。可以同时勾选人人视频与爱一帆，也可以选择腾讯、优酷、爱奇艺、芒果和 Bilibili。点应用后生效，取消不改变选择。没有保存过选择时默认启用全部来源；全部取消会停止自动查找来源，不会偷偷重新选回默认值。

来源设置用于后续播放，同一会话里可复用已匹配来源切换显示。每一家的匹配状态与当前时段数量分别显示；失败或为空不会取消其他已勾选来源，可以重新匹配所选来源。匹配仍核对公开片名、年份、季和集数，不为增加数量放宽同名作品或集数校验。

## 回退修复

- 暂停和缓冲期间也观察时间位置，回退立即清除未来位置的屏幕弹幕。
- 位置跳变使旧分段请求失效，晚到的旧窗口不会覆盖回退后的数据。
- 按住回退键连续定位时，等待 180 毫秒稳定后获取分段；恢复播放会立即获取当前窗口，避免下载风暴。
- 键盘、步进按钮和远端同步定位先清除旧弹幕，再由实际位置事件确认新的时间轴。

## 数据与取消

最多三家平台同时匹配，各自有超时和取消。先取得的有效来源先显示；这条多选路径不使用“首家成功取消其他家”。原有单源 API 的兼容行为保留。

每次合并仅保留当前位置附近的窗口，最多 6000 条；密集排序和去重在后台执行。显示每批仍最多 4 条，并在来源间轮换，避免一家的密集弹幕挤掉另一家。跨源近似同一时刻的相同文本去重。

磁盘缓存保留来源标签；通用 XML/JSON 导入器继续将导入弹幕标为本地，未改变其信任边界。缓存和来源设置不包含播放地址、NAS 路径或凭据。

## 验证边界

自动化覆盖暂停／缓冲回退、旧预取晚到、连续回退请求收敛、双源同时加载、单家故障隔离、取消、合并去重与密度、来源过滤、缓存重开和选择窗口操作。真实剧集的弹幕数量及平台可用性仍由各平台实际返回决定；最终播放体验需本机验收。
