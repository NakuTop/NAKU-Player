# Home Display 3.2.2 持久授权

NAS 登录有效时，展示授权绑定当前账号保存在 macOS 钥匙串或 Android/Windows 已有安全存储中。30 天有效的展示凭据在到期前自动续期；续期不再要求云端每四分钟重新连接 NAS。有效凭据在短暂断网时保留，用户退出 NAS、忘记账号或切换账号后不能复用旧账号授权。

兼容旧版五分钟协议；服务端先发布，客户端再升级。客户端拒绝跨站跳转、不安全 cookie、过期凭据以及账号不匹配的缓存。真正被服务端拒绝的凭据不能借网络错误回退。

验证：Swift 原生授权/恢复/退出/重启/账号隔离夹具通过；Dart 授权、网页、TV 快照与 NAS 测试通过。真实手机/TV/Windows 和长期运行验收需与构建结果分开记录。
