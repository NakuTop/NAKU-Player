# 弹幕与离线下载

## Bilibili 弹幕

播放动漫或切换集数时，自动按当前 Bangumi 作品与集号加载 Bilibili 弹幕，无需粘贴链接。显示仍由播放器的弹幕开关以及「弹幕设置 → 默认开启弹幕」控制；Bilibili 来源筛选需保持开启。

先用内置 [bangumi-data](https://github.com/bangumi-data/bangumi-data) 编号映射确定番剧版本，再用分集资料中的真实集号取得弹幕池。预告片和特别篇不会通过列表顺序冒充正片。没有编号映射时，检索中文名、原名，只有名称、年份能核对且版本唯一时才自动加载。

匹配不明确或 B 站采用跨季连续编号时，打开「弹幕切换 → 重新匹配本集弹幕（Bilibili）」。界面已带入当前动漫名与集数，可搜索别名、确认版本和分集；数字集号的版本与偏移保存后，后续集数自动沿用。成功加载的弹幕缓存到本机供离线重用；手动导入的单集覆盖优先，无痕模式不写入新缓存或匹配记录。

「手动链接（可选）」仍接受完整的 `www.bilibili.com/video/BV…`、`/bangumi/play/ep…`、`/bangumi/media/md…` 链接或 BV、av、ep、ss、md 编号。短链接需先在浏览器展开。链接中的 `?p=2` 或 ep 编号预选对应分集。

只向 Bilibili 自身接口请求公开资料和弹幕，不使用弹弹play AppId、不读取浏览器 Cookie，也不登录 B 站。没有对应番剧、接口受限或没有公开弹幕时会提示，不能保证每部番剧都可获取。接口只提供当前公开弹幕池，不等于全部历史弹幕；片头、剪辑不同可用弹幕时间偏移功能校准。

## 本地弹幕与弹弹play

「导入本集弹幕」接受 Bilibili XML（`<d p="…">`）以及弹弹play JSON（数组或 `comments` 数组），文件最多 8 MB。支持滚动、顶部、底部文本弹幕，过滤无效时间和不支持的特殊类型。导入文件只读取，不修改原文件。重新导入会替换当前集数的本地缓存；手动选择线上弹弹play分集会解除该集本地覆盖。

弹弹play聚合弹幕是可选服务，需要自己的开发者 AppId / AppSecret。在「设置 → 弹幕 → 弹弹play（可选）」填写后可测试连接并保存。macOS 凭据仅保存在本机钥匙串，不参与同步和备份。已配置时优先尝试聚合服务；未配置或该服务无法匹配时使用 Bilibili 自动匹配。申请和发布配置见[构建文档](RELEASING.md)。

显示区域、透明度、边框、字体和来源筛选改动立即作用于已打开的动漫播放器，无需重启。Bilibili/本地导入当前服务于动漫播放器；电影/剧集本次新增下载和下一集按钮。

## 下载与续播

- 电影、剧集、高清直链：在详情页点「下载」，或在播放器点「下载选集」（窄窗口放在「更多选项」），选择下载线路与所需集数，可全选整季；无需先播放。电影单集默认选中，播放器默认选中当前集。
- 动漫：详情页点「下载」后按 Kazumi 原方式选来源，再选下载集数；播放器的下载按钮打开同一个面板。已有下载或排队的集数标记为已添加，不重复提交。
- 整季选择一次写入队列，然后按并发限制在后台逐集解析。暂停后旧结果不重新启动任务；失败任务重试时重新解析页面地址。下载过程中可继续浏览或播放。
- 媒体连接受「设置 → 网络设置 → 视频直连」控制。默认为跟随系统/应用代理；开启直连后新视频请求直接连接服务器。失败任务可修改连接方式后重试。
- 主侧栏「下载管理」统一显示进度，支持暂停、继续、优先下载、删除及已完成视频的本地播放。左上角返回按钮回到之前的页面；直接进入下载页时返回主界面。关闭应用会停止任务，下次打开后可继续。
- macOS 默认开启「下载设置 → 下载时防止自动休眠」，从等待解析到传输结束持续生效；全部暂停、失败或完成后自动释放。允许熄屏、锁屏及关闭窗口后留在托盘，真正退出程序会停止下载。MacBook 合盖或用户手动选择系统睡眠仍会休眠，睡眠中不能下载；醒来后可继续未完成任务。这使用系统活动声明，不修改全局电源设置。参见 [Apple 电源管理说明](https://developer.apple.com/documentation/iokit/kiopmassertiontypepreventuseridlesystemsleep)。
- 设置中的下载目录、并发集数和分片数继续有效。保存采用原始视频流，不做降清晰度转码；实际画质取决于源，最高码率优先不代表视频一定是 4K。
- 从下载管理播放会使用本地文件，沿用原作品身份和续播进度。「继续观看」找到同一集已完成的影视下载时优先打开本地文件。未下载的集数仍需要网络；断网时海报、榜单和线上检索可能不可用。

支持 HTTP(S) 可直接取得的视频文件及常见 HLS 点播。HLS 同时保存独立音轨、初始化片段、AES-128密钥和分片；DRM、DASH或直播不属于当前离线支持范围。页面可播放并不保证其媒体地址允许下载。失效地址、网页响应或不完整传输会显示失败，不以“完成”掩盖问题。请按来源授权使用下载内容。
