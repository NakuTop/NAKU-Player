# 弹幕与离线下载

## Bilibili 弹幕

在动漫播放器打开「弹幕切换」，选择「从 Bilibili 加载本集弹幕」。输入完整的 `www.bilibili.com/video/BV…`、`/bangumi/play/ep…` 链接，或 BV、av、ep、ss 编号。短链接请先在浏览器中展开，再复制完整链接。

点击「读取视频」，检查作品名和分集，选择「应用到本集」。链接中的 `?p=2` 或 ep 编号会预选对应分集；不会用同名作品自动替换当前弹幕。只向 Bilibili 自身接口请求公开资料和弹幕，不使用弹弹play AppId、不读取浏览器 Cookie，也不登录 B 站。接口受限或没有弹幕时会提示，不能保证每部番剧都可获取。

成功加载的弹幕绑定当前 Bangumi 作品和集数，保存到本机，下次在线播放和离线播放优先读取。Bilibili 来源筛选控制这些弹幕；主动导入时会开启该来源。接口只提供当前公开弹幕池，返回数量不等于全部历史弹幕。片头、剪辑不同可用现有弹幕偏移功能校准。

## 本地弹幕与弹弹play

「导入本集弹幕」接受 Bilibili XML（`<d p="…">`）以及弹弹play JSON（数组或 `comments` 数组），文件最多 8 MB。支持滚动、顶部、底部文本弹幕，过滤无效时间和不支持的特殊类型。导入文件只读取，不修改原文件。重新导入会替换当前集数的本地缓存；手动选择线上弹弹play分集会解除该集本地覆盖。

弹弹play自动检索需要本项目自己的开发者 AppId / AppSecret。在「设置 → 弹幕 → 弹幕服务配置」填写后可测试连接并保存。macOS 凭据仅保存在本机钥匙串，不参与同步和备份。没有凭据时仍可用 Bilibili 链接和本地导入，不会伪造请求签名。申请和发布配置见[构建文档](RELEASING.md)。

显示区域、透明度、边框、字体和来源筛选改动立即作用于已打开的动漫播放器，无需重启。Bilibili/本地导入当前服务于动漫播放器；电影/剧集本次新增下载和下一集按钮。

## 下载与续播

- 电影、剧集、高清直链：视频开始播放后点击「下载本集」，窗口和全屏都有入口。解析地址失效时，可重新播放后再次添加，或切换其他线路。
- 动漫：播放器下载按钮打开选集面板，选择所需集数。
- 主侧栏「下载管理」统一显示进度，支持暂停、继续、优先下载、删除及已完成视频的本地播放。关闭应用会停止任务，下次打开后可继续。
- 设置中的下载目录、并发集数和分片数继续有效。保存采用原始视频流，不做降清晰度转码；实际画质取决于源，最高码率优先不代表视频一定是 4K。
- 从下载管理播放会使用本地文件，沿用原作品身份和续播进度。「继续观看」找到同一集已完成的影视下载时优先打开本地文件。未下载的集数仍需要网络；断网时海报、榜单和线上检索可能不可用。

支持 HTTP(S) 可直接取得的视频文件及常见 HLS 点播。HLS 同时保存独立音轨、初始化片段、AES-128密钥和分片；DRM、DASH或直播不属于当前离线支持范围。页面可播放并不保证其媒体地址允许下载。失效地址、网页响应或不完整传输会显示失败，不以“完成”掩盖问题。请按来源授权使用下载内容。
